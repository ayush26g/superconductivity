### About the Experiment 

This interactive virtual experiment simulates the phenomena of Superconductivity and the Meissner Effect. Users can explore how dropping temperatures below the critical threshold ($T_c$) triggers zero electrical resistance and expels external magnetic flux lines, demonstrating magnetic levitation through real-time interactive parameters.
